# Echoes of the Fifty Six Worlds: Requiem of the Maid

> *A dark fantasy visual novel about a maid who has died 55 times, and the 56th life where she finally chooses to stay.*

[![Python Version](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey)]()

**Echoes of the Fifty Six Worlds** (formerly *Fifty-Six Lives*) is a self-contained visual novel engine and original story built entirely in **Python** and **Tkinter**. It requires no external game engine (like Ren'Py) to run, making it a lightweight, easy-to-modify project for anyone looking to learn how a visual novel works under the hood.

## 🎭 About the Game

You are **Mika**, a quiet maid summoned to the kingdom of Vallhelm to save it from the Demon Lord. There is only one problem: you have done this 55 times before. Each time, you died, your memories were wiped, and you were reborn to do it again.

In your 56th life, you refuse to be a pawn. You will navigate political assassins, starving goblins, ancient prophecies, and your own trauma. Whether you find love, peace, or repeat the cycle is entirely up to you.

---

## ✨ Key Features

*   **32 Story Chapters** across 6 distinct Arcs (from *A Hero in a Maid's Dress* to *The Fifty-Sixth Dawn*).
*   **3 Endings** (Home, Peace, and the Cycle) determined by your choices.
*   **Reputation System**: Mika is viewed as **Good**, **Neutral**, or **Bad** based on how you treat the people around her. This changes the dialogue *within* the same scene.
*   **Dynamic Outcomes**: Choices trigger unique dialogue sequences *before* moving to the next scene.
*   **Procedural 8-Bit Voice Acting**: Every character has a unique synthesized "voice" (pitch and cadence) that plays as text types out.
*   **Typewriter Text & Skip Mode**: Read at your own pace, or fast-forward through text you've already seen.
*   **Immersive Mode**: Press `H` to hide all UI elements and enjoy the backgrounds and character art.
*   **3 Save Slots** with timestamps and chapter previews.
*   **Jukebox/Soundtrack Menu**: Listen to any of the 32 chapter tracks directly from the title screen.
*   **Screen Shake & Text Tags**: Dramatic scenes feature screen shake, and you can use `[shake]` and `[color=#ff0000]` tags in your own dialogue modifications.

## 🚀 How to Play

### Prerequisites
*   Python 3.10 or newer.
*   A system capable of playing `.mp3` and `.wav` files.

### Installation & Running
1.  **Clone the repository**:

    git clone https://github.com/phantom-nightmare-code/fifty-six-lives-visual-novel.git
    cd fifty-six-lives-visual-novel
    
    
Install dependencies:
    pip install -r requirements.txt
    
Run the game:
    python main.py
